#  Savu sapņu ceļojumu saraksta sistēma "Šurpu turpu"
## Obligātās funkcionālās prasības
 - Lietotnei ir vismaz 4 savstarpēji saistīti ekrāni/skati, kas nodrošina pilnvērtīgu lietotāja darba plūsmu;
 - Vismaz viena pilna CRUD funkcionalitāte (izveide, lasīšana, labošana, dzēšana (Create, read, update, delete)) kādam datu tipam;
 - Tiek veikta datu saglabāšana datubāzē;
 - Vismaz 2 ievades laukiem vai formām ir ieviesta datu validācija.
 - Kļūdaini ievadīti dati neļauj saglabāt ierakstu, un lietotājam tiek parādīts saprotams kļūdas paziņojums;
 - Visas galvenās funkcijas ir pieejamas un darbojas bez kritiskām kļūdām lietošanas laikā;
 - Pēc veiksmīgas darbības (izveide, labošana, dzēšana) lietotājs saņem apstiprinājuma paziņojumu vai redz rezultātu;
 - Dzēšanas darbībai tiek prasīts lietotāja apstiprinājums;
 - Lietotājs var meklēt vai filtrēt datus pēc vismaz viena kritērija.

## Obligātās nefunkcionālās prasības
- Lietotnes lietotāja saskarne ir konsekventa - visos ekrānos izmantots vienots dizains, krāsas un navigācijas elementi
- Lietotne nodrošina lietotājam saprotamus kļūdu un informācijas paziņojumus;
- Lietotne demonstrācijas/lietošanas laikā darbojas bez kritiskām kļūdām un neparedzētas darbības pārtraukšanas;
- Lietotāja saskarne saglabā funkcionalitāti dažādos loga izmēros (responsīvs vai adaptīvs izkārtojums);
- Lietotne izmanto vienotu datumu, laika un skaitļu attēlošanas formātu visā sistēmā.
